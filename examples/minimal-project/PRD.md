# 离线任务清单 Web 产品 PRD

## 1. 目标用户与核心任务

目标用户是一名需要整理当日工作事项的个人产品负责人。核心任务是在本地把一条待办事项写入清单，并看到确定的完成提示。

## 2. 输入、处理与输出

输入是一条不含个人敏感信息的短文本待办。系统在本地离线保存并回显该事项；输出是包含该事项和“已记录”状态的清单条目。

## 3. 用户主流程与确认点

用户输入待办、检查回显结果、确认符合预期。开始技术实现前需要技术适配审批；阶段完成后需要阶段验收审批。

## 4. V1 范围与优先级

V1 仅包含单用户、本地离线的待办写入和回显，优先验证一条完整核心链路。不包含账户、多人协作、云同步、公开访问、部署、模型能力或图像能力。

## 5. 验收标准

给定一条普通文本待办，用户能看到相同文本和“已记录”结果。中断后重新打开时，已保存的结果仍可检查；错误输入应给出可理解提示。

## 6. 模型、成本与平台约束

外部调用预算为 0，禁止模型调用、网络请求、付费服务和云平台资源。产品仅作为本地 Web 产品阶段的离线示例。

## 7. 数据、隐私、性能与部署

不得收集、上传或处理敏感数据。示例只使用人工编写的普通文本；不部署、不公开访问。单条待办的本地回显应在用户操作后立即可见。
